# History Period

Проект **History period** — это веб-приложение, разработанное с использованием **React**, **TypeScript**, **styled-components** и **Webpack**. В проекте используются библиотеки **Swiper** для реализации слайдеров и **GSAP** для JavaScript-анимаций.

## 📦 Технологии

- **React.js**
- **TypeScript**
- **Webpack**
- **styled-components** — стилизация компонентов
- **Swiper** — слайдеры
- **GSAP (GreenSock Animation Platform)** — анимации

## ⚙️ Требования

Для запуска проекта требуется:

- **Node.js**: `v22.20.0`
- **Yarn**: `1.22.22`

## 🚀 Установка и запуск

### 1. Установка зависимостей

```bash
yarn install
```

### 2. Сборка проекта

```bash
yarn build
```

### 3. Запуск проекта в режиме разработки

```bash
yarn dev
```

### 4. Запуск проекта в режиме продакшен

```bash
yarn dev
```
